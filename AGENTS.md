# For agents

You are on the **Grok Obsidian Brain**. Mode A unless Obsidian MCP tools are connected.

**Every session, read first:** [`GROK.md`](./GROK.md), [`PROFILE.md`](./PROFILE.md), [`MEMORY.md`](./MEMORY.md), [`CONTEXT.md`](./CONTEXT.md), [`RULES.md`](./RULES.md). If today's daily note is missing, create `01-Daily/YYYY-MM-DD.md` from [`Templates/Daily.md`](./Templates/Daily.md). Do not touch `.obsidian/` or `05-Archives/`.

If you are **Claude** (Claude Code, Claude Desktop, Claude in the API): also read [`CLAUDE.md`](./CLAUDE.md).

If you are a **different agent** (Cursor, Codex, Aider, GitHub Copilot, others): also start with [`README.md`](./README.md). The PM Brain itself is a folder of markdown files plus one `CLAUDE.md` in the working directory (see `example-brain/`). The canonical skill lives at [`.claude/skills/pm-brain/`](./.claude/skills/pm-brain/) for environments that support the `SKILL.md` format.
